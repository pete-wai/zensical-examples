# Automatic navigation and file selection

The sidebar is generated from the documents, without a `nav` list. It includes the visible page. The hidden page is published as `hidden.html` but omitted from the automatic sidebar. Draft and excluded sources are omitted from production builds.

[Open the hidden page](hidden.md) · [Open the visible page](visible.md)

The file selection rules are not access controls. A hidden page is still published and searchable.
