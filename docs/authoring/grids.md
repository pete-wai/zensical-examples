# Grids


Cards are useful for a small collection of equally important options.

<div class="grid cards" markdown>

- **Plan**

    ---

    Identify the audience and define the outcome.

- **Draft**

    ---

    Write a short example and explain its result.

- **Review**

    ---

    Test the example and check the links.

</div>

## Block grid

A generic grid can hold arbitrary Markdown blocks, including a note and a list.

<div class="grid" markdown>

!!! tip "Draft"
    Start with the reader's task and the expected outcome.

- Review the code
- Test the commands
- Check the links

</div>

