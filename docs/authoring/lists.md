# Lists and tasks


Indent continuation paragraphs and nested blocks by four spaces.

1. Prepare the release notes.
2. Review the changes.

    Ask a second reviewer to check the migration steps.

3. Publish the documentation.

- [x] Verify the examples
- [x] Check internal links
- [ ] Announce the release

Artifact
:   A file produced by a build, such as a package or report.

Release candidate
:   A proposed release awaiting final checks.

## Nested steps

Task lists can sit alongside ordered instructions. Checkboxes in this site are illustrative; their state is not saved.

1. Prepare the change.
    - [x] Open the branch
    - [ ] Update the example
2. Request a review.
    - [ ] Confirm the build
    - [ ] Ask a reviewer

??? abstract "Show Markdown source"

    ``````markdown
    1. Prepare the change.
        - [x] Open the branch
        - [ ] Update the example
    2. Request a review.
        - [ ] Confirm the build
        - [ ] Ask a reviewer
    ``````
