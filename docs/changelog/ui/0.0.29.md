# Zensical UI 0.0.29

Released 2026-09-11 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.29)

Anchor redirects help preserve links to renamed headings. Self-hosted GLightbox styles and navigation toggles for pruned sections are fixed.

## New and improved

- Heading-level redirects preserve links to an old anchor when a section moves or is renamed. [Commit `769134a`](https://github.com/zensical/ui/commit/769134a)

## Fixes

- Self-hosted GLightbox styles load correctly ([issue #220](https://github.com/zensical/ui/issues/220)). [Commit `f251f4c`](https://github.com/zensical/ui/commit/f251f4c)
- Pruned sections containing only an index no longer show a misleading toggle ([issue #215](https://github.com/zensical/ui/issues/215)). [Commit `5836d81`](https://github.com/zensical/ui/commit/5836d81)
