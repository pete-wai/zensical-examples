# Zensical UI 0.0.34

Released 2026-09-30 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.34)

The `content.action.copy` feature adds a button for copying a page as down-leveled Markdown. Dependency updates include Preact 11 and 12 new icons.

## New and improved

- The `content.action.copy` control can copy a page as down-leveled Markdown. [Commit `8fa545c`](https://github.com/zensical/ui/commit/8fa545c)
