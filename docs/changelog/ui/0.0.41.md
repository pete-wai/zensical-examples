# Zensical UI 0.0.41

Released 2026-10-30 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.41)

Search tag filtering and HTML escaping of descriptions are fixed. Image galleries now restrict slides to the active color scheme.

## Fixes

- Galleries show only images for the active light or dark theme ([issue #296](https://github.com/zensical/ui/issues/296)). [Commit `2382910`](https://github.com/zensical/ui/commit/2382910)
- Site and page descriptions are HTML-escaped before rendering. [Commit `bcdd0f9`](https://github.com/zensical/ui/commit/bcdd0f9)
- A bitmap negation boundary is corrected, fixing tag filtering in search ([issue #293](https://github.com/zensical/ui/issues/293)). [Commit `280ff5a`](https://github.com/zensical/ui/commit/280ff5a)
