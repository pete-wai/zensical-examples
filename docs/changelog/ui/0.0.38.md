# Zensical UI 0.0.38

Released 2026-10-20 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.38)

Header accessibility, long table-of-contents entries, and Mermaid state note colors improve. The release adds 26 Lucide icons and removes a vulnerable CSS build dependency.

## Fixes

- State diagram notes use theme text colors for readability ([issue #273](https://github.com/zensical/ui/issues/273)). [Commit `1bb03fd`](https://github.com/zensical/ui/commit/1bb03fd)
- Header toggle controls provide labels to assistive technology using hidden text ([issue #274](https://github.com/zensical/ui/issues/274)). [Commit `061104c`](https://github.com/zensical/ui/commit/061104c)
- Long table-of-contents words receive an ellipsis while entries can still wrap ([issue #271](https://github.com/zensical/ui/issues/271)). [Commit `d61af50`](https://github.com/zensical/ui/commit/d61af50)
