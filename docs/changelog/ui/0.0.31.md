# Zensical UI 0.0.31

Released 2026-09-19 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.31)

Index-only sections no longer produce empty submenus. Modern-theme task list checkboxes are adjusted, and the icon set grows by 60.

## New and improved

- Dependencies and the bundled icon collection are updated. [Commit `8b631ab`](https://github.com/zensical/ui/commit/8b631ab)

## Fixes

- Index-only sections no longer show empty submenus ([issue #228](https://github.com/zensical/ui/issues/228)). [Commit `ec2adfb`](https://github.com/zensical/ui/commit/ec2adfb)

## Maintenance and compatibility

- Task list checkboxes have improved sizing and alignment in the modern theme. [Commit `81a9000`](https://github.com/zensical/ui/commit/81a9000)
