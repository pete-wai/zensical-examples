# Zensical UI 0.0.33

Released 2026-09-28 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.33)

Both themes gain mkdocstrings backlink styling. GLightbox styles after instant navigation, Mermaid label colors, and the `/` search shortcut are fixed.

## New and improved

- Both themes provide styling for autorefs backlinks. [Commit `a406071`](https://github.com/zensical/ui/commit/a406071)

## Fixes

- Image galleries retain their styles after instant navigation ([issue #243](https://github.com/zensical/ui/issues/243)). [Commit `49cc6da`](https://github.com/zensical/ui/commit/49cc6da)
- Custom Mermaid node label colors are respected ([issue #241](https://github.com/zensical/ui/issues/241)). [Commit `caa15db`](https://github.com/zensical/ui/commit/caa15db)
- The `/` keyboard shortcut opens search reliably. [Commit `2ba6c99`](https://github.com/zensical/ui/commit/2ba6c99)
