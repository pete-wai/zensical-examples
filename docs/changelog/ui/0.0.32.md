# Zensical UI 0.0.32

Released 2026-09-22 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.32)

Native blog templates and a redesigned modern post sidebar add configurable icons and improved author and metadata layouts. The classic theme is unchanged.

## New and improved

- Projects can choose icons used by the modern blog sidebar. [Commit `948e990`](https://github.com/zensical/ui/commit/948e990)
- The modern blog sidebar has revised author and metadata layouts. [Commit `96e4237`](https://github.com/zensical/ui/commit/96e4237)
- Native templates render blog pages for the new blog integration. [Commit `0b52392`](https://github.com/zensical/ui/commit/0b52392)

## Fixes

- Search highlighting is skipped when the query has no remaining terms ([issue #235](https://github.com/zensical/ui/issues/235)). [Commit `91c4f52`](https://github.com/zensical/ui/commit/91c4f52)
