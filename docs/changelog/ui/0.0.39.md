# Zensical UI 0.0.39

Released 2026-10-26 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.39)

Mermaid 12 support updates diagram styling across themes. Anchor handling and scroll restoration improve for reloads and browser history, and 16 icons are added.

## New and improved

- Mermaid 12 diagrams can render with updated styles across both color schemes ([issue #259](https://github.com/zensical/ui/issues/259)). [Commit `f2e8d02`](https://github.com/zensical/ui/commit/f2e8d02)

## Fixes

- Reloads and history navigation restore scroll positions more like the browser ([issue #284](https://github.com/zensical/ui/issues/284)). [Commit `b60e016`](https://github.com/zensical/ui/commit/b60e016)
- Following the same anchor repeatedly avoids unnecessary history updates ([issue #279](https://github.com/zensical/ui/issues/279)). [Commit `8f4636d`](https://github.com/zensical/ui/commit/8f4636d)
- Rapid Back and Forward navigation no longer applies stale scroll positions ([issue #279](https://github.com/zensical/ui/issues/279)). [Commit `7ae2ea9`](https://github.com/zensical/ui/commit/7ae2ea9)
- Returning to a fragment restores the saved scroll position. [Commit `ce8a1f5`](https://github.com/zensical/ui/commit/ce8a1f5)
- A navigation without a fragment clears cached anchor state. [Commit `09824ed`](https://github.com/zensical/ui/commit/09824ed)
- Instant navigation avoids applying stale tracking updates ([issue #279](https://github.com/zensical/ui/issues/279)). [Commit `67bf3d0`](https://github.com/zensical/ui/commit/67bf3d0)
