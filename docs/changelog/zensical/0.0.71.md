# Zensical 0.0.71

Released 2026-10-16 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.71)

Support for `mkdocs-include-markdown-plugin` makes included Markdown available to migrated projects. Fixes cover unset social card colors, file discovery restarts, and oversized search fields.

This release includes [UI 0.0.37](../ui/0.0.37.md).

## New and improved

- The include-markdown integration can insert content from other Markdown files. [Commit `db5f22e`](https://github.com/zensical/zensical/commit/db5f22e)

## Fixes

- Social cards keep palette defaults when colors are not set ([issue #1041](https://github.com/zensical/zensical/issues/1041)). [Commit `7430b0c`](https://github.com/zensical/zensical/commit/7430b0c)
- The manylinux AArch64 wheel is built on a native ARM runner ([issue #1040](https://github.com/zensical/zensical/issues/1040)). [Commit `62a6e6b`](https://github.com/zensical/zensical/commit/62a6e6b)
- File discovery no longer causes unnecessary preview restarts ([issue #1035](https://github.com/zensical/zensical/issues/1035)). [Commit `812f06b`](https://github.com/zensical/zensical/commit/812f06b)
- Search index construction reports fields that exceed its size limit. [Commit `391e658`](https://github.com/zensical/zensical/commit/391e658)
