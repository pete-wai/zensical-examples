# Zensical 0.0.69

Released 2026-10-08 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.69)

Native support for `nav-weight` and `markdownextradata` expands MkDocs compatibility. This release also improves symlink watching, Unicode minification, and emoji preservation in Markdown exports.

This release includes [UI 0.0.36](../ui/0.0.36.md) ([update commit](https://github.com/zensical/zensical/commit/389ad14)).

## New and improved

- Navigation items can be ordered using the nav-weight compatibility integration. [Commit `2225649`](https://github.com/zensical/zensical/commit/2225649)
- The markdownextradata integration can make configured data available to Markdown processing. [Commit `8e96dd1`](https://github.com/zensical/zensical/commit/8e96dd1)

## Fixes

- Emoji survive conversion into llmstxt Markdown exports ([issue #1019](https://github.com/zensical/zensical/issues/1019)). [Commit `3f5f089`](https://github.com/zensical/zensical/commit/3f5f089)
- HTML minification no longer crashes on multibyte characters in attribute values ([issue #1013](https://github.com/zensical/zensical/issues/1013)). [Commit `b976a85`](https://github.com/zensical/zensical/commit/b976a85)
- Files under watched directory symlinks are included in watching. [Commit `7b22d2a`](https://github.com/zensical/zensical/commit/7b22d2a)
- Changes to symlinked watched dependencies are handled during preview ([issue #1010](https://github.com/zensical/zensical/issues/1010)). [Commit `4924fea`](https://github.com/zensical/zensical/commit/4924fea)
