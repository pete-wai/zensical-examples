# Zensical 0.0.67

Released 2026-09-30 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.67)

Native `social`, `llmstxt`, and `exclude` replacements add social cards and metadata, Markdown exports, and file exclusions. Social cards can use bundled or custom layouts.

This release includes [UI 0.0.34](../ui/0.0.34.md) ([update commit](https://github.com/zensical/zensical/commit/a55e52c)).

## New and improved

- The native llmstxt integration generates Markdown exports for downstream readers. [Commit `9f9b25b`](https://github.com/zensical/zensical/commit/9f9b25b)
- Native social card generation produces images and social metadata from bundled or custom layouts. [Commit `f7596cf`](https://github.com/zensical/zensical/commit/f7596cf)
- Native exclusion rules can remove selected files from site output. [Commit `4c2b8e2`](https://github.com/zensical/zensical/commit/4c2b8e2)
- GitHub-style admonition syntax can be rendered using the native compatibility integration. [Commit `b324149`](https://github.com/zensical/zensical/commit/b324149)

## Fixes

- Blog views honor project-supplied templates ([issue #990](https://github.com/zensical/zensical/issues/990)). [Commit `f648bb3`](https://github.com/zensical/zensical/commit/f648bb3)
