# Zensical 0.0.70

Released 2026-10-12 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.70)

MkDocs projects can use `exclude_docs`, `draft_docs`, and `not_in_nav` to exclude files, preview drafts, and omit pages from automatic navigation.

This release includes [UI 0.0.37](../ui/0.0.37.md) ([update commit](https://github.com/zensical/zensical/commit/3d11502)).

## New and improved

- MkDocs file-selection settings can exclude files, omit drafts from production, and hide pages from automatically generated navigation. [Commit `75995d9`](https://github.com/zensical/zensical/commit/75995d9)
