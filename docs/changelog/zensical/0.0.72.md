# Zensical 0.0.72

Released 2026-10-23 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.72)

The privacy plugin gains support, while Markdown extension order, fenced code defaults, links, and overlapping directories move closer to MkDocs behavior. Template edits made within the same second are detected, and `rustls` receives a security update.

This release includes [UI 0.0.38](../ui/0.0.38.md) ([update commit](https://github.com/zensical/zensical/commit/7cfd5f6)).

## New and improved

- The privacy integration can download supported external assets for local serving. [Commit `581fc01`](https://github.com/zensical/zensical/commit/581fc01)

## Fixes

- HTML character references are decoded before a URL is rewritten. [Commit `1dd7988`](https://github.com/zensical/zensical/commit/1dd7988)
- Configured polyfill script entries are normalized before use ([issue #1075](https://github.com/zensical/zensical/issues/1075)). [Commit `3f3c8a7`](https://github.com/zensical/zensical/commit/3f3c8a7)
- Invalidate cached output when templates change within the same second, including during preview. [Commit `b37107b`](https://github.com/zensical/zensical/commit/b37107b)
- URL rewriting operates on HTML attribute values without rewriting surrounding markup. [Commit `967bfec`](https://github.com/zensical/zensical/commit/967bfec)
- The file watcher handles ext4 inode reuse during file changes. [Commit `47cf4da`](https://github.com/zensical/zensical/commit/47cf4da)
- Files shared by overlapping documentation and theme directories remain available to the build. [Commit `878aaad`](https://github.com/zensical/zensical/commit/878aaad)
- SuperFences respects the configured order of Markdown extensions. [Commit `36fc72a`](https://github.com/zensical/zensical/commit/36fc72a)
- File reads no longer trigger unnecessary watcher work. [Commit `e0bf56d`](https://github.com/zensical/zensical/commit/e0bf56d)
- The bundled `rustls` dependency is patched for a security vulnerability. [Commit `55186fb`](https://github.com/zensical/zensical/commit/55186fb)
- Markdown links ending in a slash resolve to their intended pages. [Commit `dc85f5f`](https://github.com/zensical/zensical/commit/dc85f5f)
- Fenced code blocks work with the default Markdown configuration. [Commit `75bbdae`](https://github.com/zensical/zensical/commit/75bbdae)
- The preview server reports each address on which it listens ([issue #1050](https://github.com/zensical/zensical/issues/1050)). [Commit `d5086f1`](https://github.com/zensical/zensical/commit/d5086f1)
- Search field limits count token positions during indexing ([issue #1046](https://github.com/zensical/zensical/issues/1046)). [Commit `b4a4804`](https://github.com/zensical/zensical/commit/b4a4804)
