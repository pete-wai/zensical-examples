# Zensical 0.0.60

Released 2026-09-08 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.60)

Direct support for `table-reader` removes the need to route it through macros. A Windows fix also makes macro template includes work with extended-length paths.

This release includes [UI 0.0.28](../ui/0.0.28.md) ([update commit](https://github.com/zensical/zensical/commit/82ece74)).

## New and improved

- The table-reader integration now renders supported data files, including CSV, without a macros wrapper. [Commit `3b929cc`](https://github.com/zensical/zensical/commit/3b929cc)

## Fixes

- Macro template includes now accept Windows extended-length paths, so those paths no longer prevent the include from being resolved ([issue #914](https://github.com/zensical/zensical/issues/914)). [Commit `206b6b3`](https://github.com/zensical/zensical/commit/206b6b3)
