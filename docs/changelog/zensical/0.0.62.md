# Zensical 0.0.62

Released 2026-09-13 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.62)

Obsidian-style callouts can be rendered as admonitions through `mkdocs-callouts`. Plugin settings are accepted more flexibly, and watching the configuration file no longer breaks builds.

This release includes [UI 0.0.30](../ui/0.0.30.md) ([update commit](https://github.com/zensical/zensical/commit/65a019d)).

## New and improved

- Obsidian-style callouts work through the `mkdocs-callouts` compatibility integration, which enables the corresponding quotes extension ([issue #938](https://github.com/zensical/zensical/issues/938)). [Commit `d8fbb05`](https://github.com/zensical/zensical/commit/d8fbb05)

## Fixes

- Listing the configuration file in `watch` no longer breaks the build ([issue #934](https://github.com/zensical/zensical/issues/934)). [Commit `5c0bd36`](https://github.com/zensical/zensical/commit/5c0bd36)
- Existing `mike` settings are accepted more flexibly when loading a configuration ([issue #932](https://github.com/zensical/zensical/issues/932)). [Commit `13fd89e`](https://github.com/zensical/zensical/commit/13fd89e)

## Maintenance and compatibility

- Plugin configuration validation is less restrictive for compatibility with existing projects. [Commit `9f36bb5`](https://github.com/zensical/zensical/commit/9f36bb5)
