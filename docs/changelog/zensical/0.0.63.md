# Zensical 0.0.63

Released 2026-09-19 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.63)

Local preview rebuilds pages when included snippets change. Hidden files are excluded from published output, and preview root redirects and 404 responses are corrected.

This release includes [UI 0.0.31](../ui/0.0.31.md) ([update commit](https://github.com/zensical/zensical/commit/a771962)).

## Fixes

- Preview rebuilds a page when a file used by its snippets changes ([issue #950](https://github.com/zensical/zensical/issues/950)). [Commit `dfe8f94`](https://github.com/zensical/zensical/commit/dfe8f94)
- The preview server redirects its root to a URL with the expected trailing slash ([issue #944](https://github.com/zensical/zensical/issues/944)). [Commit `d6cd5d5`](https://github.com/zensical/zensical/commit/d6cd5d5)
- Hidden files and directories are kept out of the generated site ([issue #945](https://github.com/zensical/zensical/issues/945)). [Commit `2070bf1`](https://github.com/zensical/zensical/commit/2070bf1)
