# Release history

Zensical 0.0.60 through 0.1.0 brought native blog, social cards, Markdown exports, new MkDocs compatibility, and the beta milestone. These entries explain changes from the official releases and link to the supporting commits.

The main package and its UI have independent version numbers. A main release may carry the same UI forward, while UI 0.0.40 shipped the new package before main 0.0.74 adopted UI 0.0.41. The version pairing is recorded in each main release and in `data/releases.json`; carried-forward pairings are labeled there.
