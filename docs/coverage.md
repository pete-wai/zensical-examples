# Capability inventory

This inventory tracks the documentation families and plugin compatibility entries reviewed for this showcase. It does not claim exhaustive coverage of every option, combination, browser, or platform.

The local environment was checked with Zensical 0.1.0, UI 0.0.41, Python 3.13.15, and uv 0.12.19. These version checks do not verify the behavior of every example.

**147 entries have example source; 6 are gaps; 2 are explicitly unsupported upstream.** An example status means only that its source path exists. A gap can include a source illustration that is not a working demonstration. Per-feature behavior is unverified unless an entry explicitly records a verified version.

The official documentation changes over time. This snapshot was reviewed on 2026-11-08; compare its navigation and compatibility lists when updating it. A source path points to the repository, and may be a configuration file rather than a rendered page.
