# See what Zensical can do

A feature name rarely tells you whether you need it. These examples show the result, give it a practical use, and let you try it.

This showcase runs **Zensical 0.1.0 with UI 0.0.41**. Every live page uses Zensical's native rendering. Independently built mini-sites let you compare settings that cannot change on an individual page.

## How to use this site

Start with the rendered example. Expand **Source** when you want to see how the content was written. Configuration links lead to the official documentation; this site concentrates on what the options do.

A **Live demo** link opens another native Zensical build within this site. Each has a return link. Some examples deliberately hide navigation or change the language, so a different-looking interface is expected.

## What's covered?

The [coverage register](coverage.md) tracks documented authoring, setup, and compatibility capabilities. External services are explained without connecting accounts. Paid or separately distributed extensions are identified explicitly. The source repository includes a repeatable update workflow and validation tools.

This is an independent project, inspired by [OWID's demo page](https://docs.owid.io/projects/etl/guides/demo/). It is not official Zensical documentation.
