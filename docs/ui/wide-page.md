# Room for a comparison

[← Return to page-level layout](page-layout.md)

Both sidebars are hidden on this page. The site header and its navigation tabs still work. Compare this page with the explanation page to see the native layout change.

| Option | What readers see | Useful when | Tradeoff |
| --- | --- | --- | --- |
| Both sidebars | Navigation and page headings | A long reference page | Less space for wide content |
| Navigation only | Site structure | A short article | No heading overview |
| Neither | Content takes priority | A landing page or comparison | Fewer visible navigation cues |

## A second use: a short introduction

A concise product overview may need only a few links to the next steps. Hiding a largely empty contents sidebar avoids giving it unnecessary space.
