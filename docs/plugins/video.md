# video

Embed video with native browser controls or an iframe. Native support was added in Zensical **0.0.68**.

Add a short demonstration to a tutorial; embed a remote training video.

## Try it

[Open the video example](/zensical-examples/variants/video/).

### Local playback

Play the local MP4 using the browser’s native controls.

### Reusable marker

The same clip appears beside a second instruction with independent controls.
