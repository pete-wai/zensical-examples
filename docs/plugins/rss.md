# rss

Generate feeds for newly created and updated pages. Native support was added in Zensical **0.0.65**.

Publish release notes to feed readers; let readers subscribe to documentation updates.

## Try it

[Open the rss example](/zensical-examples/variants/rss/).

### Created feed

Open the RSS created feed and inspect the dated example page.

### Updated feed

Open the updated feed and find the second dated Spring update.
