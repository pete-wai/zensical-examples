# macros

Render Jinja variables and Python macros in Markdown. Native support was added in Zensical **0.0.40**.

Reuse a product name or version across pages; generate repeated links with a helper.

## Try it

[Open the macros example](/zensical-examples/variants/macros/).

### Variable

The trip name is supplied by `main.py` and rendered into the page.

### Python macro

The greeting is generated by a Python function called from Markdown.
