# literate-nav

Define navigation with a Markdown list of links. Native support was added in Zensical **0.0.58**.

Keep a book’s table of contents in Markdown; curate a tutorial sequence that authors can edit.

## Try it

[Open the literate-nav example](/zensical-examples/variants/literate-nav/).

### Markdown navigation

The sidebar order comes from a Markdown list in `SUMMARY.md`.

### Linked page

Select Field notes to follow the second link in that list.
