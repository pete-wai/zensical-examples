# section-index

Attach a section landing page to its navigation entry. Native support was added in Zensical **0.0.3**.

Give each handbook section an introduction; make a section title lead to its overview.

## Try it

[Open the section-index example](/zensical-examples/variants/section-index/).

### Section landing page

Select Field guide in the sidebar to open its overview.

### Child page

Select Equipment beneath that section to open a separate page.
