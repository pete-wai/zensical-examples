# audio

Turn marked Markdown images into browser audio players. Native support was added in Zensical **0.0.68**.

Add pronunciation clips to a language guide; include short sound samples in a field guide.

## Try it

[Open the audio example](/zensical-examples/variants/audio/).

### Local playback

Play the generated 440 Hz tone with the native audio controls.

### Playback settings

The same WAV recording appears beside a second exercise with its own controls.
