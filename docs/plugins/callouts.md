# callouts

Render Obsidian-style callouts as admonitions. Native support was added in Zensical **0.0.62**.

Bring notes from an Obsidian vault into a site; highlight warnings in operational guides.

## Try it

[Open the callouts example](/zensical-examples/variants/callouts/).

### Note

The note callout renders as an admonition with a custom title.

### Warning

The warning uses the same Obsidian-style syntax with a different type.
