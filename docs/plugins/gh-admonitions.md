# gh-admonitions

Render GitHub-style alerts as admonitions. Native support was added in Zensical **0.0.67**.

Reuse a GitHub README in documentation; distinguish tips and warnings in a migration guide.

## Try it

[Open the gh-admonitions example](/zensical-examples/variants/gh-admonitions/).

### Tip

The GitHub-style TIP block renders as an admonition.

### Warning

The WARNING block shows a second alert type using README-compatible syntax.
