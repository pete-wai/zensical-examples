# redirects

Create redirects from old paths to new locations. Native support was added in Zensical **0.0.58**.

Preserve bookmarks after renaming a page; move a section into a new guide.

## Try it

[Open the redirects example](/zensical-examples/variants/redirects/).

### Renamed page

Open the old guide URL to follow its generated redirect.

### Destination

A second old URL redirects to the kit page.
