# glightbox

Open images in an interactive lightbox. Native support was added in Zensical **0.0.35**.

Let readers inspect a diagram; present a gallery of screenshots with captions.

## Try it

[Open the glightbox example](/zensical-examples/variants/glightbox/).

### Image lightbox

Click the mountain diagram to open it in a lightbox.

### Caption

A second image opens independently with its own alternative text as the caption.
