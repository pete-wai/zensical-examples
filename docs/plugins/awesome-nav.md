# awesome-nav

Define navigation in per-directory YAML files. Native support was added in Zensical **0.0.58**.

Curate a guide independently of the site configuration; order groups with a directory-level navigation file.

## Try it

[Open the awesome-nav example](/zensical-examples/variants/awesome-nav/).

### Curated order

The sidebar places Start before Field notes according to `.nav.yml`.

### Named navigation

The label “Field notes” comes from the navigation file and links to the notes page.
