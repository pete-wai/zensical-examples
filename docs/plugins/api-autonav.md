# api-autonav

Generate API pages and navigation from Python packages. Native support was added in Zensical **0.0.66**.

Keep a library reference in sync with a growing package; expose public modules without maintaining a page for each one.

## Try it

[Open the api-autonav example](/zensical-examples/variants/api-autonav/).

### Generated package reference

Open **API Reference → samplelib** in the sidebar to inspect the generated package page.

### Function reference

The generated page includes the `greet` function and its argument and return documentation.
