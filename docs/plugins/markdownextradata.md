# markdownextradata

Render Jinja templates with project and data-file variables. Native support was added in Zensical **0.0.69**.

Share a product name across a site; load a directory of structured data for a feature matrix.

## Try it

[Open the markdownextradata example](/zensical-examples/variants/markdownextradata/).

### Product name

The example renders the product name from `project.extra`.

### Release number

A second variable supplies the release number from the same settings.
