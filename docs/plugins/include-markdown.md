# include-markdown

Include shared Markdown or text in multiple pages. Native support was added in Zensical **0.0.71**.

Reuse an installation prerequisite; keep a shared support policy in one file.

## Try it

[Open the include-markdown example](/zensical-examples/variants/include-markdown/).

### Shared prerequisite

A separate Markdown file supplies the water-bottle paragraph.

### Shared checklist

A second included file supplies a reusable packing checklist.
