# tags

Categorize pages and generate tag listings. Native support was added in Zensical **0.0.58**.

Group guides by topic; offer readers another way to browse a collection.

## Try it

[Open the tags example](/zensical-examples/variants/tags/).

### Shared tag

The Fieldwork listing contains both Field notes and Equipment.

### Additional tag

Preparation lists Equipment independently.
