# markdown-exec

Run marked code blocks and insert their output. Native support was added in Zensical **0.0.47**.

Keep calculated examples current; show the result of a small Python snippet.

## Try it

[Open the markdown-exec example](/zensical-examples/variants/markdown-exec/).

### Arithmetic

The Python block calculates a six-kilometer round trip.

### Formatted output

A second block formats a checklist into Markdown during the build.
