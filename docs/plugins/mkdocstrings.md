# mkdocstrings

Build API reference sections from source docstrings. Native support was added in Zensical **0.0.11**.

Document a public function next to a tutorial; generate class reference material from maintained source.

## Try it

[Open the mkdocstrings example](/zensical-examples/variants/mkdocstrings/).

### Function signature

The `greet` directive renders a Python signature.

### Docstring

Its arguments and return value come from the function’s source docstring.
