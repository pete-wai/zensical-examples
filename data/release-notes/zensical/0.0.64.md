# Zensical 0.0.64

Released 2026-09-22 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.64)

Native blog support brings over familiar Material for MkDocs configuration, including authors, categories, archives, pagination, metadata, and post URLs.

This release includes [UI 0.0.32](../ui/0.0.32.md) ([update commit](https://github.com/zensical/zensical/commit/a85875e)).

## New and improved

- The native blog implementation handles posts, archives, categories, authors, and pagination using familiar plugin configuration. [Commit `5825381`](https://github.com/zensical/zensical/commit/5825381)
