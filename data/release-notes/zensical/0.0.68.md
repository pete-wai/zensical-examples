# Zensical 0.0.68

Released 2026-10-05 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.68)

Native replacements for the `audio` and `video` plugins arrive alongside closer macros compatibility. Python 3.10 support is removed: Python 3.11 or newer is required.

This release includes [UI 0.0.35](../ui/0.0.35.md) ([update commit](https://github.com/zensical/zensical/commit/7662853)).

## New and improved

- Native audio and video integrations convert their configured Markdown markers to media embeds. [Commit `00fe88a`](https://github.com/zensical/zensical/commit/00fe88a)

## Fixes

- Macros behavior was brought closer to the original plugin; consult the linked issue for the specific compatibility case ([issue #999](https://github.com/zensical/zensical/issues/999)). [Commit `acee50c`](https://github.com/zensical/zensical/commit/acee50c)
