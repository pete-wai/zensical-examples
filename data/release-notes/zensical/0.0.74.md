# Zensical 0.0.74

Released 2026-10-30 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.74)

Support for `optimize` joins fixes to redirects, blog dates, validation, privacy downloads, and `llms.txt`. UI assets are now sourced from the separate `zensical-ui` Python package.

This release uses [UI 0.0.41](../ui/0.0.41.md) ([update commit](https://github.com/zensical/zensical/commit/e5aa684)).

UI 0.0.40 introduced the separate package before [UI 0.0.41](../ui/0.0.41.md) was adopted in this release. See the [0.0.40 notes](../ui/0.0.40.md) for that packaging change.

## New and improved

- The optimize integration can process supported local images during a build. [Commit `df2ba1c`](https://github.com/zensical/zensical/commit/df2ba1c)
- Templates and browser assets are loaded from the separate `zensical-ui` Python package. [Commit `91d4e31`](https://github.com/zensical/zensical/commit/91d4e31)

## Fixes

- Internal redirects retain query strings. [Commit `b4890c3`](https://github.com/zensical/zensical/commit/b4890c3)
- Blog dates follow the configured locale ([issue #1097](https://github.com/zensical/zensical/issues/1097)). [Commit `7e0784a`](https://github.com/zensical/zensical/commit/7e0784a)
- Images addressed by URL remain in llmstxt exports ([issue #1095](https://github.com/zensical/zensical/issues/1095)). [Commit `49132b7`](https://github.com/zensical/zensical/commit/49132b7)
- Legacy validation configuration and the `relative_to_docs` value remain compatible ([issue #1060](https://github.com/zensical/zensical/issues/1060)). [Commit `6292939`](https://github.com/zensical/zensical/commit/6292939)
- Privacy downloads use configured custom certificate bundles ([issue #1089](https://github.com/zensical/zensical/issues/1089)). [Commit `7bab4ef`](https://github.com/zensical/zensical/commit/7bab4ef)
