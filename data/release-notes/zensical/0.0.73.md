# Zensical 0.0.73

Released 2026-10-26 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.73)

Privacy-plugin URL rewriting now handles JavaScript-loaded assets on nested pages and during preview. The nested list example in new projects is also corrected.

This release includes [UI 0.0.39](../ui/0.0.39.md) ([update commit](https://github.com/zensical/zensical/commit/f039e8b)).

## Fixes

- The starter project uses sufficient indentation for its nested list example. [Commit `d68bd2c`](https://github.com/zensical/zensical/commit/d68bd2c)
- Privacy rewriting now resolves JavaScript-loaded assets on nested pages and in local preview ([issue #1080](https://github.com/zensical/zensical/issues/1080)). [Commit `9d1b114`](https://github.com/zensical/zensical/commit/9d1b114)
