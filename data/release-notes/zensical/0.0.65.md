# Zensical 0.0.65

Released 2026-09-24 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.65)

The native RSS replacement produces RSS 2.0 and JSON Feed 1.1 feeds. Support for mkdocstrings backlinks lets API pages show their referring pages, including across cached builds.

This release includes [UI 0.0.32](../ui/0.0.32.md).

## New and improved

- Support mike's `version_selector` setting. [Commit `e7876ab`](https://github.com/zensical/zensical/commit/e7876ab)
- Support mkdocstrings' `enable_inventory` setting. [Commit `25b95e9`](https://github.com/zensical/zensical/commit/25b95e9)
- Support additional macros settings for selecting pages and controlling verbose output. [Commit `0223fc9`](https://github.com/zensical/zensical/commit/0223fc9)
- Support autorefs settings for closest-target resolution, generated link titles, and title-tag stripping. [Commit `acee89a`](https://github.com/zensical/zensical/commit/acee89a)
- API documentation can show links back to pages that reference an object. [Commit `0291923`](https://github.com/zensical/zensical/commit/0291923)
- The native RSS integration can generate feeds for created and updated pages ([issue #443](https://github.com/zensical/zensical/issues/443)). [Commit `c214988`](https://github.com/zensical/zensical/commit/c214988)

## Fixes

- Links to blog source files resolve to the published post URLs ([issue #966](https://github.com/zensical/zensical/issues/966)). [Commit `cf68f6d`](https://github.com/zensical/zensical/commit/cf68f6d)
