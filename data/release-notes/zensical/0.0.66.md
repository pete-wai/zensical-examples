# Zensical 0.0.66

Released 2026-09-28 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.66)

Support for `mkdocs-autoapi` and `mkdocs-api-autonav` helps projects generate and organize Python API references. Sitemap coverage, responsive image URLs, and custom InlineHilite formatters also improve.

This release includes [UI 0.0.33](../ui/0.0.33.md) ([update commit](https://github.com/zensical/zensical/commit/3d8c0e2)).

## New and improved

- Python API pages and their navigation can be generated from source modules using the autoapi and api-autonav integrations. [Commit `b2f4de7`](https://github.com/zensical/zensical/commit/b2f4de7)

## Fixes

- Custom InlineHilite formatters resolve from TOML configuration ([issue #980](https://github.com/zensical/zensical/issues/980)). [Commit `7be3d1d`](https://github.com/zensical/zensical/commit/7be3d1d)
- Published pages are no longer omitted from the generated sitemap ([issue #977](https://github.com/zensical/zensical/issues/977)). [Commit `e3099ab`](https://github.com/zensical/zensical/commit/e3099ab)
- Responsive image `srcset` URLs in raw HTML resolve relative to the Markdown source ([issue #975](https://github.com/zensical/zensical/issues/975)). [Commit `e24d0fc`](https://github.com/zensical/zensical/commit/e24d0fc)
