# Zensical 0.0.61

Released 2026-09-11 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.0.61)

Redirects can preserve old heading links when pages are renamed or split. Redirect chains are resolved and cycles rejected; the release also expands configuration support for page redirects.

This release includes [UI 0.0.29](../ui/0.0.29.md) ([update commit](https://github.com/zensical/zensical/commit/eac9e24)).

For example, an anchor redirect can preserve a link after a heading is renamed:

```toml
[project.plugins.redirects.redirect_maps]
"guide.md#installation" = "guide.md#getting-started"
```

See the [redirect documentation](https://zensical.org/docs/setup/redirects/#redirect-a-section) for configuration details.

## New and improved

- A redirect can pass through multiple mappings to its final destination; cycles are rejected. [Commit `215d7fa`](https://github.com/zensical/zensical/commit/215d7fa)
- A page redirect can apply an explicit destination anchor. [Commit `a6fdc5f`](https://github.com/zensical/zensical/commit/a6fdc5f)
- Heading-level redirects preserve links to an old anchor when a section moves or is renamed. [Commit `0b1a378`](https://github.com/zensical/zensical/commit/0b1a378)

## Fixes

- Existing autorefs configurations are accepted more flexibly. [Commit `6910d56`](https://github.com/zensical/zensical/commit/6910d56)
- Server doctests avoid competing for the same port. [Commit `78a34cd`](https://github.com/zensical/zensical/commit/78a34cd)
- Existing search configurations are accepted more flexibly ([issue #926](https://github.com/zensical/zensical/issues/926)). [Commit `304e280`](https://github.com/zensical/zensical/commit/304e280)

## Maintenance and compatibility

- Redirect planning and output were refactored for clarity. [Commit `6220f43`](https://github.com/zensical/zensical/commit/6220f43)
