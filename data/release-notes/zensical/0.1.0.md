# Zensical 0.1.0

Released 2026-11-05 · [Upstream release notes](https://github.com/zensical/zensical/releases/tag/v0.1.0)

This milestone begins the beta release line after the 0.0.x series. The release focuses on MkDocs compatibility, configuration validation, templates, URL handling, and dependency updates.

This release uses [UI 0.0.41](../ui/0.0.41.md).

## Fixes

- Update vulnerable dependencies, including the `swc` CSS stack and `lexical` crates. [Commit `340c3ac`](https://github.com/zensical/zensical/commit/340c3ac)
- Configured and inherited static templates remain available to the build. [Commit `d6fdf6e`](https://github.com/zensical/zensical/commit/d6fdf6e)
- Invalid MkDocs-compatible configuration is caught before the build runs. [Commit `0d8201a`](https://github.com/zensical/zensical/commit/0d8201a)
- Extra template paths and their warnings behave more like MkDocs. [Commit `3acbefe`](https://github.com/zensical/zensical/commit/3acbefe)
- Extra scripts use MkDocs-compatible module inference. [Commit `1ccc67a`](https://github.com/zensical/zensical/commit/1ccc67a)
- URL configuration and generated page links follow the approved MkDocs-compatible behavior. [Commit `ab99f8f`](https://github.com/zensical/zensical/commit/ab99f8f)
