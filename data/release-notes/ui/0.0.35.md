# Zensical UI 0.0.35

Released 2026-10-05 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.35)

Search results use instant navigation, avoiding repeated full-page loads. Skip-link targets and accessible names for overlays and progress indicators are corrected.

## Fixes

- Opening a search result uses instant navigation instead of reloading the entire page ([issue #252](https://github.com/zensical/ui/issues/252)). [Commit `d5354e6`](https://github.com/zensical/ui/commit/d5354e6)
- Skip links consistently lead to page content ([issue #250](https://github.com/zensical/ui/issues/250)). [Commit `be6b7c5`](https://github.com/zensical/ui/commit/be6b7c5)
- Overlay and progress controls expose corrected accessible names. [Commit `5e34ab8`](https://github.com/zensical/ui/commit/5e34ab8)
