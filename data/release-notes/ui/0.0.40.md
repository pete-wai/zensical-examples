# Zensical UI 0.0.40

Released 2026-10-27 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.40)

The new `zensical-ui` Python package ships templates, browser assets, and icons separately. It includes prebuilt assets and supports editable installs for UI development.

## New and improved

- Templates, icons, and prebuilt browser assets are packaged for separate installation as `zensical-ui`. [Commit `b9019fb`](https://github.com/zensical/ui/commit/b9019fb)
