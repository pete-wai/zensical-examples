# Zensical UI 0.0.37

Released 2026-10-12 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.37)

Search gains better keyboard focus, labels, announcements, initialization, and error handling. Draft markers and discovery links for Markdown and `llms.txt` are added, alongside 17 icons.

## New and improved

- Draft markers receive styling in the themes. [Commit `6d87cbc`](https://github.com/zensical/ui/commit/6d87cbc)

## Fixes

- Search results gain improved accessibility and rendering. [Commit `2a04bab`](https://github.com/zensical/ui/commit/2a04bab)
- Search keyboard interaction and client rendering are updated. [Commit `c912822`](https://github.com/zensical/ui/commit/c912822)
- Pages expose discovery links for llms.txt and Markdown alternatives ([issue #264](https://github.com/zensical/ui/issues/264)). [Commit `d6669ba`](https://github.com/zensical/ui/commit/d6669ba)
