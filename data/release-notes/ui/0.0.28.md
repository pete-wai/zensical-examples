# Zensical UI 0.0.28

Released 2026-09-08 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.28)

Pruned navigation and alternate-link handling are corrected. The build toolchain and dependencies are updated, and 51 icons are added.

## Fixes

- Development dependencies were updated to address reported vulnerabilities. [Commit `f278185`](https://github.com/zensical/ui/commit/f278185)
- Pruned navigation sections link to their index pages. [Commit `647006b`](https://github.com/zensical/ui/commit/647006b)
- Pruned navigation retains the section title ([issue #215](https://github.com/zensical/ui/issues/215)). [Commit `ccfebcd`](https://github.com/zensical/ui/commit/ccfebcd)
- Alternate links are loaded only when they declare `hreflang` ([issue #213](https://github.com/zensical/ui/issues/213)). [Commit `5d072aa`](https://github.com/zensical/ui/commit/5d072aa)
