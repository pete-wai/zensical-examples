# Zensical UI 0.0.36

Released 2026-10-08 · [Upstream release notes](https://github.com/zensical/ui/releases/tag/v0.0.36)

Navigation spacing is refined, and instant navigation handles anchors without an `href` again.

## Fixes

- Code symbols have clearer spacing in navigation and breadcrumbs ([issue #260](https://github.com/zensical/ui/issues/260)). [Commit `352c211`](https://github.com/zensical/ui/commit/352c211)
- Links without an `href` no longer disrupt instant navigation ([issue #256](https://github.com/zensical/ui/issues/256)). [Commit `8b183c3`](https://github.com/zensical/ui/commit/8b183c3)
